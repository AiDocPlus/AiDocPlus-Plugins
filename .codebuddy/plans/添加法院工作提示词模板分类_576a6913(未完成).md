## 用户需求

研究提示词模板管理体系，增加"法院工作"分类，确保对法院工作的全覆盖。

## 产品概述

在 AiDocPlus-PromptTemplates 外部仓库中新增 `court.json` 分类文件，面向法院工作人员，提供覆盖法律文书起草、案件分析、司法公文三大场景的提示词模板。

## 核心功能

- 创建"法院工作"分类（key: court，order: 6）
- 法律文书起草：民事判决书、刑事判决书、行政判决书、裁定书、调解书、执行裁定书
- 案件分析：案情摘要、证据分析报告、法律适用分析、合议庭评议笔录
- 司法公文：开庭公告、传票、应诉通知书、执行通知书、司法建议书

## 技术栈

- 数据格式：JSON
- 数据目录：`/Users/jdh/Code/AiDocPlus-PromptTemplates/data/`
- 构建脚本：`scripts/build.py` → 生成 `dist/*.generated.ts`
- 部署脚本：`scripts/deploy.sh`

## 数据格式规范

```
{
  "key": "court",
  "name": "法院工作",
  "icon": "⚖️",
  "order": 6,
  "templates": [
    {
      "id": "court-judgment-civil",
      "name": "民事判决书",
      "description": "撰写民事判决书",
      "content": "# 民事判决书助手\n\n## 角色设定\n...",
      "variables": [],
      "order": 0,
      "authorNotes": "",
      "tags": [],
      "aiGeneratedContent": "",
      "enabledPlugins": [],
      "includeContent": false,
      "includeAiContent": false
    }
  ]
}
```

## 实现方案

参考现有 `police.json` 和 `procuratorial.json` 的格式和内容结构，创建 `court.json` 文件。

### 模板内容设计原则

1. **角色设定**：资深法官/书记员角色
2. **业务范围**：清晰的业务分类表格
3. **内容结构**：首部、正文、尾部的标准文书结构
4. **写作要求**：专业性、规范性、合法性要求
5. **质量标准**：可量化的质量检验标准
